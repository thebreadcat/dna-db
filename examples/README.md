# DNA-DB Examples

High-impact, fast-to-run demos:

- `01_no_index_queries`
- `02_privacy_overlays`
- `03_schema_evolution`
- `04_hybrid_queries`
- `05_high_write_events`
- `06_benchmark_quick`
- `quick-demo`

Each example is intentionally small:

```bash
npm install
node index.js
```

For the one-minute walkthrough:

```bash
cd quick-demo
npm install
node run.js
```
