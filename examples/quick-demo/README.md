# Example: Quick Demo

## What this shows
One-minute proof of ingest speed, no-index querying, and privacy overlays.

## Run it
```bash
npm install
node run.js
```

## What to notice
- Inserts 100k records.
- Runs a filtered query.
- Applies a support-role privacy mask.

## Why this matters
It is a compact walkthrough of DNA-DB's core differentiators.
